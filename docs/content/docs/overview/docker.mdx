# Docker Deployment

## Use the published image

```bash
git clone git@github.com:basketikun/infinite-canvas.git
cd infinite-canvas
docker compose up -d
```

Open `http://localhost:3000/canvas/`.

## Build locally

```bash
docker compose -f docker-compose.local.yml up -d --build
```

The published frontend is built under `/canvas/`. For a site-specific image, pass the three build arguments explicitly and build a separate image for each site:

```bash
docker build --build-arg VITE_BASE=/canvas/ \
  --build-arg VITE_FIXED_API_BASE_URL=https://your-site.example \
  --build-arg VITE_DOCS_URL=https://your-site.example/docs/ \
  -t infinite-canvas:site .
```

Build the Artwork image locally with its dedicated profile, which serves the page on `artworkers.online`, brands the page as `artworkers`, fixes the model API to `https://artworkers.online`, and uses `https://artworkers.online/docs/image` for documentation:

```bash
docker compose -f docker-compose.artworkers.yml build
```

Production Blue/Green deployment uses the verified image archive from this local build.

## Documentation image

The documentation in `docs/` is a separate Next.js standalone application with server capabilities.

```bash
cd docs
docker compose up -d
```

To build it from the current source:

```bash
cd docs
docker compose -f docker-compose.local.yml up -d --build
```

The main application container only runs the static Nginx frontend. Canvases, My Assets, generation history, and API keys are stored in the browser by default, while prompt repositories are fetched directly by the frontend. No persistent data volume is required for this data.

## Optional analytics

No analytics are enabled by default. A deployment can enable GA4, Baidu Analytics, or both at runtime:

| Variable | Description |
| --- | --- |
| `ANALYTICS_GA4_ID` | Google Analytics 4 measurement ID (`G-XXXX`) |
| `ANALYTICS_BAIDU_ID` | Baidu site ID, the hash after `hm.js?` |

```yaml
services:
  app:
    image: ghcr.io/basketikun/infinite-canvas:latest
    ports:
      - "3000:3000"
    environment:
      ANALYTICS_GA4_ID: G-XXXXXXXXXX
      ANALYTICS_BAIDU_ID: e8263761cc5c32f5f7a855b8203b965a
```

SPA route changes automatically report page views to enabled providers. Only configure analytics IDs on sites you control, and do not commit them to the repository.
